# PDF Noter

[![License: AGPL-3.0](https://img.shields.io/badge/License-AGPL--3.0-blue.svg)](LICENSE)

Репозиторий: <https://github.com/victor1810/PDF-Noter>

Небольшая **свободная** программа для просмотра PDF и работы с аннотациями под Windows 10/11.

Это **не порт и не взломанная копия PDF-XChange Viewer**. В исходной папке лежал только
закрытый Windows-инсталлятор репака без исходных кодов, поэтому он не может быть
пересобран под другую ОС. Здесь — независимая реализация на Python/PySide6 + PyMuPDF
с необходимым минимальным набором функций.

## Возможности

- Открытие PDF через диалог, перетаскивание файла в окно или аргумент командной строки.
- **Непрерывная прокрутка**: все страницы расположены вертикально одной лентой,
  рендерятся только страницы в области видимости и по соседству с ней.
- Масштабирование (колесо мыши + Ctrl), «по странице» / «по ширине».
- Навигация по страницам (PgUp / PgDown, поле номера страницы на панели).
- **Отмена и повтор действий** на панели инструментов и в меню «Правка»
  (`Ctrl+Z` / `Ctrl+Y` или `Ctrl+Shift+Z`), история на 20 шагов. Отменяются
  аннотации, операции со страницами, импорт изображений и OCR.
- **Страницы**: вставить пустую после текущей (`Ctrl+Shift+Return`), добавить в конец,
  удалить текущую (`Ctrl+Del`, с подтверждением; последнюю страницу удалить нельзя).
- **Импорт изображений** в PDF как новых страниц (вставляются после текущей):
  - из файлов `PNG / JPEG / BMP / TIFF / GIF / WebP`, в том числе многостраничный TIFF
    (`Ctrl+I`, кнопка на панели или перетаскивание файлов в окно);
  - из буфера обмена (`Ctrl+Shift+V`);
  - со сканера через Windows WIA (`Ctrl+Shift+I`) — системный диалог выбора устройства;
  - с веб-камеры (`Ctrl+Shift+C`) — предпросмотр и съёмка кадра.
  Размер страницы вычисляется из DPI изображения (по умолчанию 150 dpi).
- Аннотации:
  - выделение, подчёркивание, зачёркивание текста (протянуть рамку по тексту);
  - заметка (щелчок + текст);
  - текстовое поле (протянуть рамку + текст);
  - карандаш (свободная линия мышью);
  - выбор аннотации и удаление клавишей Delete;
  - выбор цвета аннотаций.
- **OCR через Tesseract**: распознать текущую страницу (`Ctrl+Shift+R`) или весь документ.
  Распознанный текст добавляется невидимым слоем — страница становится доступной для
  поиска и копирования, а внешний вид скана не меняется. Язык выбирается в меню
  «Аннотации → Язык OCR» (по умолчанию `rus+eng`), запоминается между запусками.
- Сохранение изменений в исходный PDF (Ctrl+S) или в новый файл (Ctrl+Shift+S).
- **Тёмная / светлая / системная тема** (переключается в меню «Тема», запоминается между запусками).
  Системная тема на Windows читается из `AppsUseLightTheme` и обновляется через Qt.

## Требования

- Windows 10/11 x64.
- Для запуска из исходников: Python 3.10+ (рекомендуется 3.12).
- Для готового `.exe` — Python не нужен (см. «Сборка»).
- Для OCR: Tesseract-OCR и языковые данные `eng` / `rus` (устанавливаются один раз).
- Для сканирования: WIA-совместимый сканер и его драйвер (в Windows 10/11 встроена
  поддержка WIA). Для камеры — веб-камера; модуль `PySide6-Addons` уже входит в
  `requirements.txt` и в готовую сборку.

### Подготовка OCR

Запустите `install_tesseract.bat` из папки проекта: он установит Tesseract-OCR
(UB Mannheim, если его ещё нет) и положит языковые файлы в `%PUBLIC%\PdfNoter\tessdata`.
Этот путь намеренно содержит только ASCII-символы: движок Tesseract не всегда
открывает данные из папок с кириллицей в имени. Если OCR недоступен, приложение
покажет понятное сообщение с подсказкой. Альтернативно можно задать переменную
`TESSDATA_PREFIX` вручную.

### Если файл не открывается

Если вместо страниц появляется сообщение «Файл не открыт», PDF повреждён:
отсутствует каталог страниц (`/Root`, `/Catalog`, `/Pages`) или бита таблица
_xref_. Такие файлы не удаётся восстановить ни PyMuPDF, ни большинству других
просмотрщиков — скачайте документ заново или откройте его в другом приложении
и сохраните копию. Проверить файл можно так:

```bat
.venv\Scripts\python.exe -c "import pymupdf as f,sys; d=f.open(sys.argv[1]); print('pages:', len(d))" "путь\к\файлу.pdf"
```

Если `pages: 0` — файл именно повреждён. Программа не сохраняет такие документы,
чтобы не испортить исходник ещё сильнее.

## Запуск из исходников

```bat
python -m venv .venv
.venv\Scripts\activate.bat
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python src\main.py
```

Или просто `run.bat` (если пакеты уже установлены глобально).

Открыть конкретный файл:

```bat
python src\main.py C:\Path\to\document.pdf
```

## Сборка EXE

```bat
build.bat
```

Результат: `dist\PDF Noter\PDF Noter.exe` (готовая сборка уже лежит в этой папке).
Сборка использует PyInstaller в отдельном virtualenv; иконка лежит в `resources\app.ico`.
Запуск `dist\PDF Noter\PDF Noter.exe` проверен на Windows 11.

## Управление

| Действие | Клавиши / мышь |
| --- | --- |
| Открыть / сохранить / сохранить как | `Ctrl+O` / `Ctrl+S` / `Ctrl+Shift+S` |
| Отменить / повторить | `Ctrl+Z` / `Ctrl+Y` (или `Ctrl+Shift+Z`), кнопки ↶ / ↷ на панели |
| Масштаб | `Ctrl` + колесо мыши, `Ctrl++`, `Ctrl+-`, `Ctrl+0`, `Ctrl+1` |
| Страницы | `PgUp`, `PgDown`, поле номера страницы |
| Вставить страницу после текущей | `Ctrl+Shift+Return` |
| Удалить текущую страницу | `Ctrl+Del` |
| Изображения из файлов | `Ctrl+I` (или перетащите файлы в окно) |
| Изображение из буфера обмена | `Ctrl+Shift+V` |
| Сканирование (WIA) | `Ctrl+Shift+I` |
| Снимок с камеры | `Ctrl+Shift+C` |
| Прокрутка | колесо мыши; средняя кнопка — перетаскивание |
| Выбор аннотации | инструмент «Выбор», щелчок по аннотации |
| Удалить аннотацию | `Delete` |
| Вернуться к выбору | `Esc` |
| OCR текущей страницы | `Ctrl+Shift+R` |

## Тесты

```bat
python -m unittest discover -s tests -v
```

Тесты проверяют аннотации, сохранение/переоткрытие PDF, преобразование координат
для повёрнутых страниц, непрерывную прокрутку, операции со страницами, историю
отмены/повтора, импорт изображений (файлы, буфер обмена, WIA, камера), обработку
повреждённых файлов и OCR (тесты OCR пропускаются, если Tesseract не установлен).
GUI-тесты выполняются в оффскрин-режиме.

## Ограничения

- Нет заполнения интерактивных форм PDF и встроенного поиска по тексту
  (распознанный OCR-слой можно копировать и искать во внешних программах).
- Текстовые аннотации добавляются поверх существующего текста; редактирование
  существующих свойств аннотации (прозрачность, автор) не реализовано.
- OCR распознаёт отсканированные страницы, но не исправляет их изображение
  (предварительная обработка скана не предусмотрена).
- Сканер и камера зависят от оборудования и драйверов Windows: если устройство
  не найдено, приложение сообщит об этом и предложит добавить готовые файлы.

Код распространяется по лицензии **AGPL-3.0-or-later** (из-за зависимости PyMuPDF,
которая тоже AGPLv3). PySide6 распространяется по LGPLv3. Программа не использует
код, бинарники или ресурсы PDF-XChange.
